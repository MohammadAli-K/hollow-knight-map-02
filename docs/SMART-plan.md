# SMART-plan – JavaScript leren en interactieve Hollow Knight map

**Bijgewerkt op:** 25 juni 2026

---

## Hoofddoel

Binnen 14 weken leer ik de basis van JavaScript door een online cursus te volgen en deze kennis toe te passen in een project: een interactieve map van Hollow Knight.

---

## Doel 1 – JavaScript leren via freeCodeCamp

### Specifiek
Ik ga JavaScript leren via de cursus op **freeCodeCamp**. Dit doe ik door de oefeningen interactief te maken — niet door naar filmpjes te kijken, want dat werkt beter voor mijn manier van leren.

> **Correctie t.o.v. origineel:** Het plan vermeldde oorspronkelijk een Udemy-cursus (23 sections), maar dit bleek niet de cursus te zijn die ik volgde. Per 9 april 2026 is het doel bijgesteld naar freeCodeCamp.

### Meetbaar
- Platform: **freeCodeCamp**
- Doel: de cursus afronden t/m het onderwerp **Loops**
- Deadline bijgesteld doel: **14 mei 2026** (donderdag vóór Hemelvaartsdag)

**Onderwerpen die ik leer:**
- Variabelen
- Functies
- Arrays
- Objects
- Loops

### Acceptabel
Dit leerdoel past bij mijn opleiding Creative Software Development en helpt mij programmeervaardigheden te ontwikkelen die essentieel zijn voor webdevelopment.

### Realistisch
Ik besteed gemiddeld:
- 1–2 uur per dag aan JavaScript
- Ongeveer 7–10 uur per week

Dit is haalbaar naast mijn schoolwerk.

### Tijdsgebonden
- **Week 9 t/m week 11** (bijgestelde planning na 9 april): werken aan freeCodeCamp t/m Loops
- Einddatum: **14 mei 2026**

## Doel 2 – Interactieve Hollow Knight map

### Specifiek
Ik maak een interactieve kaart van de game Hollow Knight waarin gebruikers op klikbare pins kunnen klikken om informatie te zien. Het project wordt online gepubliceerd en is voor iedereen toegankelijk.

### Meetbaar

**Geplande basisfunctionaliteit (origineel plan):**
- [x] Kaartafbeelding van de gamewereld
- [x] Klikbare gebieden / pins
- [x] Informatie-popup of sidebar
- [x] Gebruik van JavaScript events
- [x] Data opslaan in objects

**Geplande extra features (origineel optioneel):**
- [x] Hover-effecten (op zoekresultaten en pins)
- [x] Filters per categorie (Show All / Hide All per type)
- [x] Progress tracker (Mark as Found per pin)

**Gerealiseerde extra features (niet gepland, maar toegevoegd):**
- [x] Werkende zoekbalk met groepering op regio en resultaatteller
- [x] Sidebar met logo, categoriefilters en Show All / Hide All knoppen
- [x] Pin-popup met naam, regio en "Mark as Found"-knop
- [x] Gebruikersaccounts (registreren en inloggen)
- [x] Gevonden pins opgeslagen in een database per gebruiker (server-side, SQLite)
- [x] Admin-pagina met drag-and-drop pin-repositioning en opslaan
- [x] Beveiliging van de admin-pagina via Cloudflare Zero Trust (e-mailcode)
- [x] Backend gebouwd met Node.js + Express, uitgerold op Railway
- [x] Eigen domeinnaam: **cornimap.com**
- [x] Mobiele ondersteuning: pinch-to-zoom (inclusief iOS Safari fix), zoom-knoppen, pin-popup als bottom sheet op kleine schermen

### Acceptabel
Het project gaat verder dan het originele plan en laat zien dat ik JavaScript niet alleen theoretisch heb geleerd, maar ook praktisch heb toegepast — inclusief onderwerpen die buiten de oorspronkelijke cursus vallen, zoals asynchrone JavaScript (fetch, async/await), server-side development en databasebeheer.

### Realistisch
Het project is verder gegaan dan gepland. Dit was haalbaar omdat de basiskennis uit freeCodeCamp snel werd uitgebreid door te werken aan een concreet project.

## Eindresultaat

Aan het einde van de 14 weken heb ik:

- De basisbegrippen van JavaScript geleerd via freeCodeCamp (variabelen, functies, arrays, objects, loops)
- Een volledig werkende, interactieve Hollow Knight map gebouwd en online gepubliceerd op **[cornimap.com](https://cornimap.com)**
- JavaScript toegepast in een echt project, inclusief DOM-manipulatie, events, fetch-verzoeken, local storage en server-side logica
- Een backend gebouwd met gebruikersaccounts, een database en een beveiligd admin-paneel
- Mobiele ondersteuning geïmplementeerd, inclusief oplossingen voor iOS Safari-specifieke bugs

Het eindresultaat gaat significant verder dan het oorspronkelijke SMART-plan en toont aan dat de opgedane kennis direct is toegepast en uitgebreid in een concreet, openbaar product.
